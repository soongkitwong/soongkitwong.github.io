# Soong Kit Wong Job Market Website

Static, GitHub Pages-ready academic job market site for Soong Kit Wong.

## Current Assets

- `index.html`: main site page
- `styles.css`: site styling
- `script.js`: mobile navigation and email-copy behavior
- `assets/headshot.jpg`: current headshot
- `assets/Soong_Kit_Wong_CV_2026.pdf`: public CV PDF
- `assets/Soong_Kit_Wong_CV_2026.docx`: editable CV source copy
- `assets/Soong_Kit_Wong_JMP.pdf`: September 28, 2026 job market paper (74 pages)
- `robots.txt`: allows crawling and advertises the sitemap
- `sitemap.xml`: lists the homepage, JMP PDF, and CV PDF

## Local Preview

Open `index.html` directly in a browser. No build step is required.

## Publish With GitHub Pages

This repository is intended to publish from the `main` branch at the repository root.

In GitHub, go to `Settings` -> `Pages`, choose `Deploy from a branch`, then set branch `main` and folder `/root`.

## Google Search

The homepage declares `https://soongkitwong.github.io/` as its canonical URL.
Publishing a sitemap helps discovery but does not guarantee indexing or ranking.
Use Google Search Console's URL-prefix property for this URL to inspect Google's
indexing status, submit `sitemap.xml`, and request indexing after material updates.

When replacing the JMP, retain its stable filename, update the displayed title,
abstract and draft label, and update the sitemap modification dates accurately.
